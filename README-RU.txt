LEAF TECHNOLOGY — ГОТОВЫЙ САЙТ

Статический сайт: HTML, CSS, JavaScript. Установка зависимостей и сборка не нужны.

Для GitHub:
1. Распакуйте архив.
2. Загрузите его содержимое в корень репозитория: index.html, остальные страницы,
   assets, styles.css, site.js и .nojekyll. Сохраняйте структуру папок.
3. Для публикации включите GitHub Pages для ветки с этими файлами,
   выбрав корневую папку репозитория.

Главная страница: index.html (английский).
Другие языки: fr-index.html, uk-index.html, ru-index.html.
Порядок языков в меню: EN / FR / UK / RU.
Для просмотра на компьютере откройте index.html в браузере.

Форма связи открывает почтовое приложение посетителя с готовым письмом
на oml.leaftechnology@gmail.com. Посетитель должен сам нажать «Отправить».
Серверная отправка и хранение заявок не подключены.

Архив содержит готовую версию для размещения, без инструментов сборки.
